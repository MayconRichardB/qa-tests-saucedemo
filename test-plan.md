# 🧪 QA Test Project - SauceDemo

Projeto de testes manuais realizado no sistema SauceDemo, com foco na validação das principais funcionalidades de um e-commerce.

---

## 🎯 Objetivo

Validar o funcionamento das funcionalidades principais do sistema, garantindo que o comportamento esteja de acordo com o esperado.

---

## 🔍 Escopo de Testes

- Login de usuário
- Adição de produtos ao carrinho
- Remoção de produtos
- Finalização de compra (checkout)

---

## 🧪 Tipos de Teste

- Testes funcionais
- Testes exploratórios

---

## 🛠️ Ambiente de Teste

- Sistema: Web
- Navegador: Google Chrome
- URL: https://www.saucedemo.com/
